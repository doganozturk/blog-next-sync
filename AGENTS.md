# Blog guidance

For post changes, read [content](docs/content.md). Preserve published URLs and the author's meaning.

For layout, color, or theme changes, read [styling](docs/styling.md).

Keep language posts independent. A translation can have its own slug.

Use class-based theme selection. Preserve keyboard focus, reduced-motion behavior, and responsive media.

Check visual changes in the production export at desktop and mobile widths. Include both themes and localized routes when the change affects them.
